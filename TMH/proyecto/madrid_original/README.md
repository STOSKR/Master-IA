# 📂 Madrid Original

Esta carpeta contiene la implementación **original** del algoritmo genético para rutas turísticas en Madrid.

## 📋 Archivos

- **`algoritmo_genetico.py`** - Algoritmo genético original para Madrid (7 días)
- **`utils.py`** - Dataset de 253 lugares turísticos reales de Madrid
- **`analisis_graficas.py`** - Scripts de análisis y visualización

## 📊 Características

- **Lugares:** 253 lugares turísticos reales de Madrid
- **Días:** 7 días de viaje
- **Complejidad:** 10^251.5
- **Restricciones:** Completas (comidas, horarios, fatiga, presupuesto, etc.)

## 🚀 Cómo ejecutar

```bash
cd madrid_original
python ejecutar_algoritmo.py
```

## 📈 Resultados típicos

- Fitness: ~8,000-10,000
- Puntos: ~850-950
- Tiempo: 90-100 horas
- Lugares visitados: ~90-100 lugares
